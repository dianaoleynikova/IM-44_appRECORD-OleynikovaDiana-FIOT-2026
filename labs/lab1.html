Опис предметного середовища. Опис бізнес-логіки

Предметне середовище

Обрана предметна галузь — управління завданнями в команді (проєктний менеджмент). У невеликих командах, зокрема студентських, завдання зазвичай розподіляють у чатах і усно: хтось забуває про дедлайн, незрозуміло, хто за що відповідає і на якому етапі перебуває робота.

Веб-застосунок TaskTracker збирає всі завдання проєкту в одному місці. Кожне завдання має виконавця, пріоритет, дедлайн і статус, а команда бачить актуальну картину роботи у вигляді таблиці та дошки.

Користувачі: учасник команди, керівник проєкту, адміністратор.

Бізнес-логіка (сценарій)

  1. Користувач реєструється в системі та входить до свого облікового запису.
  2. Керівник створює проєкт і запрошує до нього учасників.
  3. Керівник або учасник створює завдання: назва, опис, виконавець, пріоритет, дедлайн. Нове завдання отримує статус «До виконання».
  4. Виконавець отримує сповіщення та бере завдання в роботу — статус «В роботі».
  5. Після завершення виконавець переводить завдання в статус «На перевірці».
  6. Керівник перевіряє результат: приймає завдання (статус «Виконано») або повертає його в роботу з коментарем.
  7. Якщо дедлайн минув, а завдання не виконано, система позначає його як прострочене й сповіщає виконавця та керівника.
  8. Система формує звіт: кількість завдань за статусами та виконавцями, список прострочених завдань.

Функціональні вимоги

  • Реєстрація, авторизація та особистий профіль користувача.
  • Створення проєктів і запрошення учасників.
  • Створення, редагування та видалення завдань.
  • Призначення виконавця, пріоритету й дедлайну.
  • Зміна статусу за схемою «До виконання → В роботі → На перевірці → Виконано».
  • Перегляд завдань у таблиці з фільтрами та пошуком.
  • Коментарі до завдань.
  • Сповіщення на e-mail про нові завдання та наближення дедлайнів.
  • Звіти за проєктом.

Нефункціональні вимоги

  • Адаптивний інтерфейс для комп’ютера й телефону.
  • Час завантаження списку завдань — до 2 секунд.
  • Захищене зберігання паролів і персональних даних.
  • Розмежування прав доступу за ролями.
  • Підтримка сучасних браузерів.
  • Доступність: підписи до полів форм, альтернативний текст до зображень.
  • Інтерфейс українською мовою.

Структура документа

Головна сторінка WEB-застосунку TaskTracker (index.html) має таку структуру:

  • <head> — кодування, заголовок сторінки, фавікон (<link rel="icon">) і стилі кольорів посилань;
  • <header id="top"> — логотип (<img>), заголовок <h1>, короткий опис, навігація з посиланнями (<nav>, <a>), зокрема на сторінку description.html з описом предметної галузі та бізнес-логіки, і адаптивний банер (<picture>);
  • <main>
    • розділ «Завдання проєкту» — таблиця <table> з групою стовпців <colgroup> та зображення дошки завдань із картою (<map>, <area>);
    • розділ «Про сервіс» — нумерований і маркований списки, список визначень;
    • розділ «Нове завдання» — форма <form>;
  • <footer> — підвал сторінки з посиланням на репозиторій.

Заголовки різних рівнів: h1 — назва застосунку, h2 — розділи, h3 — підрозділи.

HTML-код посилань (навігація)

<nav>
  <a href="#tasks">Завдання</a> |
  <a href="#info">Про сервіс</a> |
  <a href="#new-task">Нове завдання</a> |
  <a href="description.html">Предметна галузь та бізнес-логіка</a>
</nav>

Теорія: посилання

Посилання створюється тегом <a> (anchor). Його вміст — клікабельний текст або зображення.

Атрибут Призначення
href адреса, на яку веде посилання: інша сторінка (description.html), зовнішній сайт (повна URL-адреса) або якір на цій сторінці (#tasks)
target де відкрити: _self — у цьому ж вікні (за замовчуванням), _blank — у новій вкладці
rel тип зв’язку; noopener захищає сторінку, що відкривається у новій вкладці
title підказка при наведенні курсора
id (на цільовому елементі) створює якір, до якого веде href="#id"

Закладки на сторінці

Розділи мають атрибути id (tasks, info, new-task), а початок сторінки — id="top". Навігація посилається на них через href="#id", а в кінці кожного розділу є посилання <a href="#top">↑ Нагору</a>.

Кольори посилань (CSS)

<style>
  a:link    { color: #2563eb; }
  a:visited { color: #7c3aed; }
  a:hover   { color: #dc2626; }
  a:active  { color: #f59e0b; }
  fieldset { min-width: 0; }
  th { background-color: #e8f0fb; }
  tbody tr:hover { background-color: #fff3bf; }
</style>

Псевдокласи задають колір посилання залежно від стану: a:link — не відвідане, a:visited — відвідане, a:hover — під курсором, a:active — у момент натискання.

Скрін-шот

Теорія

Таблиця створюється тегом <table>. Вона складається з рядків, а рядки — з комірок.

Тег Призначення
<table> контейнер таблиці
<caption> заголовок таблиці
<thead>, <tbody>, <tfoot> шапка, тіло та підвал таблиці
<tr> рядок таблиці
<th> комірка-заголовок (жирний текст по центру)
<td> звичайна комірка з даними
<colgroup>, <col> групування й оформлення стовпців
Атрибут Тег Призначення
border table товщина рамки таблиці
cellpadding table відступ між вмістом і межею комірки
cellspacing table відстань між комірками
span col, colgroup кількість стовпців, до яких застосовується оформлення
style col, td, th вбудований CSS (ширина, колір фону)
width, height table, td, th розміри таблиці або комірки
colspan td, th об’єднання комірок по горизонталі
rowspan td, th об’єднання комірок по вертикалі
align, valign tr, td, th вирівнювання вмісту (у сучасному HTML замінюється CSS)

У нашій таблиці rowspan="2" об’єднує дві комірки з виконавцем «Діана О.», а colspan="6" розтягує рядок підвалу на всю ширину таблиці. Елемент <colgroup> із <col> задає ширину першого стовпця (40 px) і колір фону стовпця «Статус».

Фавікон — іконка сайту у вкладці браузера. Підключається в елементі <head>.

Теорія

Зображення вставляється одинарним тегом <img>, який не має закриваючого тега.

Атрибут Призначення
src шлях до файлу зображення (обов’язковий)
alt альтернативний текст: показується, якщо зображення не завантажилось, і читається екранними програмами
title підказка при наведенні курсора
width, height розміри зображення в пікселях
usemap пов’язує зображення з картою (usemap="#boardmap")
Тег / атрибут Призначення
<map name> карта зображення; ім’я збігається зі значенням usemap
<area shape coords href alt> клікабельна область: форма (rect, circle, poly), координати, адреса, альтернативний текст
<picture>, <source media srcset> вибір зображення за умовою (наприклад, за шириною екрана); якщо жодна умова не виконана, використовується вкладений <img>
<link rel="icon" href> підключення фавікона

Шлях до файлу може бути відносним (images/logo.svg) або абсолютним (повна URL-адреса). Поширені формати: JPEG, PNG, GIF, SVG, WebP.

Теорія

Тег Призначення
<ol> нумерований список

ВИСНОВКИ

У ході лабораторної роботи №1 обрано предметну галузь «Управління завданнями в команді», описано предметне середовище, бізнес-логіку, функціональні та нефункціональні вимоги до WEB-застосунку TaskTracker. Створено репозиторії для застосунку, самостійних робіт і звітного документа та опубліковано їх на GitHub Pages.

Практично засвоєно структуру HTML-документа, роботу з таблицями (table, tr, th, td, colgroup, colspan, rowspan), зображеннями (img з атрибутами src, alt, width, height), картами зображень (map, area), адаптивними зображеннями (picture), фавіконом, посиланнями та закладками (a, href, target, id), списками (ol, ul, dl) і формами (form, input, select, textarea). Створено шаблон звітного HTML-документа, до якого надалі додаватимуться результати наступних лабораторних робіт.
