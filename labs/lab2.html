Тема ЛР №2

Каскадні таблиці стилів. Селектори тегу, класу, ідентифікатора. Стильове оформлення текстових елементів в HTML-документах.

Мета ЛР №2

Придбати практичні навички роботи з селекторами, ідентифікаторами, списками, різноманітними властивостями кольору і фону, зовнішніми та внутрішніми відступами, плаваючими елементами, оформленням текстових елементів.

Способи підключення стилів

Існують три способи задати стилі HTML-елементам:

  1. Вбудований (inline) — атрибут style в тезі елемента. Діє лише на цей елемент.
  2. Внутрішній (internal) — елемент <style> в розділі <head>. Діє на всю сторінку.
  3. Зовнішній (external) — окремий файл .css, який підключається елементом <link rel="stylesheet" href="...">. Один файл можна підключити до багатьох сторінок.

1. Вбудований стиль

HTML-код

<p style="color: #b91c1c; font-weight: bold;">Дедлайн сьогодні!</p>

Як це зроблено в TaskTracker

У index.html використано всі три способи: атрибут style (банер і обгортки таблиці), елемент <style> (кольори посилань, зроблені в ЛР №1) і зовнішній файл (основні стилі). Зовнішній файл підключено після <style>, тому при однаковій специфічності його правила виграють.

<link rel="icon" type="image/svg+xml" href="images/logo.svg">
<style> ... </style>
<link rel="stylesheet" href="css/style.css">

Каскадування і спадкування

  • Каскадування — правила розв’язання конфліктів, коли кілька правил стосуються одного елемента: перемагає правило з вищою специфічністю (вбудований стиль, потім #id, потім клас / атрибут / псевдоклас, потім тег), а за рівної специфічності — те, що записане пізніше.
  • Спадкування — передача деяких властивостей (color, font-family, line-height, text-align) від батьківського елемента до вкладених. Властивості рамок, відступів і фону не успадковуються.

Специфічність

Від найвищої до найнижчої: вбудований style → #id → .клас, [атрибут], :псевдоклас → тег, ::псевдоелемент → *. Наприклад, у TaskTracker правило #top h1 { color: #fff; } перемагає h1 { color: #2563eb; }.

Приклади кожного виду селекторів — у наступних пунктах меню.

Селектори тегу

Селектор тегу застосовує правило до всіх елементів цього типу. Селектор групи h1, h2, h3 об’єднує кілька тегів в одне правило.

У css/style.css стилі тегів задано для body, h1–h3, p, img, a.

HTML-код

<h1>TaskTracker</h1>
<h2>Завдання проєкту</h2>
<h3>Дошка завдань</h3>
<p>Трекер завдань для команди: плануйте, призначайте виконавців, відстежуйте статус.</p>
<p><a href="#">Перейти до завдань</a></p>

CSS-код

body { color: #1f2937; background-color: #f5f7fb; max-width: 960px; margin: 0 auto; padding: 0 16px 40px; }
h1 { color: #2563eb; font-size: 36px; margin: 8px 0; }
h2 { color: #1e3a8a; border-bottom: 2px solid #2563eb; padding-bottom: 4px; }
h3 { color: #1d4ed8; }
p  { margin: 8px 0; }
img { border-radius: 12px; }

Селектори класу

Клас задають атрибутом class в HTML, а в CSS — крапкою перед іменем: .status. Один клас можна використати для багатьох елементів, а елемент може мати кілька класів (class="status status-done").

У таблиці завдань TaskTracker класи задають колір пріоритету (.priority-high, .priority-mid, .priority-low) і вигляд статусу (.status та .status-done, .status-work, .status-review, .status-todo).

HTML-код

<table>
  <tr><th>Завдання</th><th>Пріоритет</th><th>Статус</th></tr>
  <tr><td>Розробити макет</td><td class="priority-high">Високий</td><td class="status status-done">Виконано</td></tr>
  <tr><td>Зверстати сторінку</td><td class="priority-mid">Середній</td><td class="status status-work">В роботі</td></tr>
  <tr><td>Налаштувати БД</td><td class="priority-high">Високий</td><td class="status status-review">На перевірці</td></tr>
  <tr><td>Написати документацію</td><td class="priority-low">Низький</td><td class="status status-todo">До виконання</td></tr>
</table>

Селектори ідентифікаторів

Ідентифікатор (id) унікальний у межах сторінки й позначає один конкретний елемент. У CSS перед іменем ставлять решітку: #top. Ідентифікатор також використовується як закладка для посилань (href="#top").

У TaskTracker стилями за ідентифікаторами оформлено шапку #top, таблицю #task-table і розділ #new-task.

HTML-код

<header id="top">
  <h1>TaskTracker</h1>
  <p>Плануйте. Призначайте. Відстежуйте.</p>
  <nav><a href="#">Завдання</a> | <a href="#">Про сервіс</a></nav>
</header>
<section id="new-task">
  <h2>Нове завдання</h2>
  <p>Тут розміщується форма створення завдання.</p>
</section>

CSS-код

#top { color: #fff; background-color: #1e3a8a; }
#top { text-align: center; padding: 20px 12px; border-radius: 0 0 16px 16px; }
#top h1 { color: #fff; }
#top a:link, #top a:visited { color: #bfdbfe; }
#new-task { background-color: #fff; border: 1px solid #cbd5e1; border-radius: 12px; padding: 4px 16px 16px; }

Сусідній селектор +

Вибирає елемент, що йде безпосередньо після іншого: оформлено лише перший список після заголовка та опис після терміна.

HTML-код

<h3>Життєвий цикл</h3>
<ol><li>Створення</li><li>Виконання</li></ol>
<ol><li>Другий список (не сусід заголовка)</li></ol>
<dl><dt>Дедлайн</dt><dd>Крайній термін виконання.</dd></dl>

CSS-код

:root { --accent: #2563eb; }
h3 + ol, h3 + ul { background-color: #fff; border-left: 4px solid var(--accent); padding: 8px 8px 8px 36px; }
dt + dd { margin-left: 24px; color: #475569; }

Селектор атрибута

Вибирає елементи за атрибутом або його значенням: поля певного типу, обов’язкові поля, посилання, що відкриваються в новій вкладці.

HTML-код

<p><input type="text" placeholder="Назва" required>
   <input type="email" placeholder="E-mail">
   <input type="submit" value="Створити"></p>
<p><a href="https://example.com" target="_blank">Репозиторій</a>
   <a href="https://example.com">Звичайне посилання</a></p>

CSS-код

input[type="text"], input[type="email"], input[type="number"], input[type="date"], select, textarea {
  border: 1px solid #94a3b8; border-radius: 6px; padding: 5px 8px;
}
input[required] { border-left: 4px solid #dc2626; }
a[target="_blank"]::after { content: " ↗"; }

Універсальний селектор *

Вибирає всі елементи. У TaskTracker він задає box-sizing: border-box для всіх елементів, а також контур при фокусі (*:focus). Для наочності нижче контур показано для всіх елементів.

HTML-код

<h2>Заголовок</h2>
<p>Абзац із <em>виділенням</em>.</p>
<ul><li>Елемент списку</li></ul>

CSS-код

ВИСНОВКИ до ЛР №2

У ході лабораторної роботи №2 було підключено до WEB-застосунку TaskTracker зовнішню таблицю стилів css/style.css і розглянуто три способи підключення стилів: вбудований, внутрішній та зовнішній.

Практично застосовано селектори тегу, групи, класу, ідентифікатора, а також дочірній, сусідній, атрибута й універсальний селектори. З’ясовано відмінність між каскадуванням (розв’язання конфліктів за специфічністю й порядком) та спадкуванням (передача властивостей від батьківських елементів).

Виконано стильове оформлення шрифтів, тексту, таблиць, фону, контурів і списків (зокрема багаторівневих), використано зовнішні та внутрішні відступи, плаваючі елементи, змінні CSS, псевдокласи, переходи та медіазапити. Результати лабораторних робіт №1 і №2 відображено у звітному HTML-документі.
